# TestPhoneApp

iOS-приложение на языке **Swift**, демонстрирующее работу с фреймворком **CallKit** для идентификации и блокировки вызовов.

## 📱 Описание проекта

Проект состоит из трех ключевых компонентов:
1. **TestPhoneApp** — основное приложение (контейнер) для управления базой номеров.
2. **TestPhoneCallDirectory** — расширение типа *Call Directory Extension*, которое интегрируется в систему iOS для фонового определения номеров и блокировки спама.
3. **Shared** — функционал, который можно вынести в kmp.

## ✨ Функционал

- **Идентификация вызовов**
- **Блокировка спама**: автоматический сброс звонков от нежелательных абонентов на системном уровне.
- **Поддержка инкрементных обновлений**: оптимизированная загрузка измененных списков номеров.

## 🛠 Требования

- **Язык**: Swift 5.x
- **Платформа**: iOS 11.0+
- **Среда разработки**: Xcode 14.0+
